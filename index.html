📚 理論說明

Q-learning（Off-policy TD Control）

Q(s,a) ← Q(s,a) + α [r + γ · maxa'Q(s',a') − Q(s,a)]
  • 更新時選取下一狀態所有動作中的最大值
  • 學習目標與行為策略解耦（Off-policy）
  • 收斂至最優 Q*，但訓練期間因探索而風險較高
初始化 Q(s,a) = 0
for 每個回合:
    s ← 起點
    while 未到達終點:
        a ← ε-greedy(Q, s)
        s', r ← env.step(a)
        Q(s,a) += α * (r + γ * max_a' Q(s',a') - Q(s,a))
        s ← s'

SARSA（On-policy TD Control）

Q(s,a) ← Q(s,a) + α [r + γ · Q(s',a') − Q(s,a)]
  • a' 為 ε-greedy 實際選取的動作（On-policy）
  • 更新反映探索策略的影響（含隨機探索風險）
  • 學到的策略更保守、穩定，適合安全敏感場景
初始化 Q(s,a) = 0
for 每個回合:
    s ← 起點
    a ← ε-greedy(Q, s)
    while 未到達終點:
        s', r ← env.step(a)
        a' ← ε-greedy(Q, s')
        Q(s,a) += α * (r + γ * Q(s',a') - Q(s,a))
        s ← s' ; a ← a'
